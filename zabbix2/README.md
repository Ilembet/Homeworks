## Задание 6. UserParameter на Bash

Скрипт возвращает ФИО при параметре `1` и текущую дату при параметре `2`:

```bash
#!/bin/bash
case $1 in
    1)
        echo "Ваши ФИО"
        ;;
    2)
        date '+%Y-%m-%d %H:%M:%S'
        ;;
    *)
        echo "Неверный параметр. Используйте 1 или 2."
        ;;
esac
```
