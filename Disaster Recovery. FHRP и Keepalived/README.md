## Задание 2. Keepalived + Bash-скрипт проверки

### Описание логики работы

Bash-скрипт `check_web.sh` выполняет две проверки:
1. **Проверка порта 80** — через `nc -z localhost 80` проверяется, доступен ли веб-сервер (nginx).
2. **Проверка наличия файла `index.html`** — подтверждается существование `/var/www/html/index.html`.

Если хотя бы одна проверка не проходит, скрипт завершается с кодом ошибки (`exit 1`), что интерпретируется Keepalived как сбой сервиса.

Секция `vrrp_script` в `keepalived.conf` определяет параметр `check_web`, который:
- Запускает скрипт каждые 3 секунды (`interval 3`).
- Считает узел неработающим после 2 последовательных неудач (`fall 2`).
- Восстанавливает статус после 2 успешных проверок (`rise 2`).

Трек-скрипт подключён в `vrrp_instance VI_1` через `track_script { check_web }`, что обеспечивает автоматический перенос плавающего IP на резервный узел при недоступности веб-сервера.

### Исходный код Bash-скрипта

```bash
#!/bin/bash
# Проверка порта 80 (nginx)
nc -z localhost 80 || exit 1
# Проверка существования файла index.html
[ -f /var/www/html/index.html ] || exit 1
exit 0
```

### Конфигурация Keepalived

```ini
vrrp_script check_web {
    script "/etc/keepalived/check_web.sh"
    interval 3    # Проверка каждые 3 секунды
    fall 2        # Считать упавшим после 2 неудач
    rise 2        # Считать живым после 2 успехов
}

vrrp_instance VI_1 {
    state MASTER
    interface enp0s8      # Замените на имя вашего интерфейса (ip a)
    virtual_router_id 51  # Должен быть одинаковым на обоих узлах
    priority 101          # Выше, чем у бэкапа
    advert_int 1

    authentication {
        auth_type PASS
        auth_pass 12345   # Общий пароль для узлов
    }

    virtual_ipaddress {
        192.168.56.100    # Ваш виртуальный (плавающий) IP
    }

    track_script {
        check_web
    }
}
```
